2. Gradle sync tugashini kuting (internet kerak).
3. Build -> Build Bundle(s) / APK(s) -> Build APK(s).

5. Teyes'ga flesh yoki ADB orqali o'rnating (Noma'lum manbalarga ruxsat bering).
